## Implementado en esta etapa

- Alta de organizacion mediante asistente de organizacion, administrador y revision; usa el endpoint atomico existente. El rol inicial se limita a ORGANIZATION_ADMIN.
- Asistente de personal valida cada paso antes de avanzar y muestra catalogos y requisitos documentales reales de la organizacion.
- Documentos registra eventos de creacion, modificacion, revision y archivo en BusinessDocumentEvents. El historial se consulta por documento y organizacion.
- EF rechaza modificaciones y eliminaciones de eventos documentales. No es una proteccion contra un administrador SQL; no se fabricaron eventos para documentos historicos.
- Se retiro el selector de privacidad sin persistencia. Sigue disponible el indicador sensible existente, sin introducir niveles de autorizacion ficticios.
- Las sesiones de soporte expiran en frontend y se validan en backend para actor y organizacion. Las rutas operativas requieren soporte para Super Admin.
- Se corrigio el redondeo de fechas de soporte: datetime2(0) podia redondear el inicio hacia el futuro y provocar un 403 inmediatamente despues del alta. Ahora se conserva datetime2(7).
- Planeacion detecta cruces de turnos entre dias consecutivos y omite versiones sustituidas en esa comprobacion.
- Solicitudes carga paginas de hasta 100 registros, respetando el limite de la API y recorriendo las siguientes paginas para el tablero.
- La compilacion Angular desactiva inlineCritical: el cargador CSS inline generado era bloqueado por la CSP del contenedor. No se relajo script-src.
- Se corrigieron desbordamientos de Personal, filtros y asistente movil, y la duplicacion de Seguridad durante soporte.
